# SYNTHETIC — demonstration of the evaluation pipeline only

Every file here was produced by running the real `evaluate.py` on outputs of `MockBackend`, a fake model
built for testing (it answers correctly 60% of the time and copies the majority 50% of the time in
discussion rounds). The figures carry a "SYNTHETIC — MOCK BACKEND" watermark and every row has `model = mock`.

These files show the **format** of results.csv, comparisons.csv, flip_rates.csv, seed_summary.csv,
integrity_report.json and the figures. **No number here may be reported or interpreted.**
